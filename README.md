# Md. Alomgir Hossain — Researcher CV Website

A static, responsive academic researcher portfolio designed for GitHub Pages.

## Files

- `index.html` — main website
- `style.css` — styling and responsive layout
- `CV.pdf` — optional; add your CV PDF here to activate the Download CV button

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
2. Add your LinkedIn URL if desired.
3. Put your CV PDF in this folder and name it `CV.pdf`.
4. Add additional publications, submitted manuscripts, projects, awards, and conference presentations as needed.

## GitHub Pages

1. Create a new GitHub repository, for example `researcher-cv`.
2. Upload `index.html` and `style.css` (and `CV.pdf` if available).
3. Open **Settings → Pages**.
4. Under the build/deployment option, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. GitHub will provide your Pages URL, typically `https://YOUR-USERNAME.github.io/researcher-cv/`.
